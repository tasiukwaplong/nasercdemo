1. EXECUTIVE OVERVIEW & PLUGIN ARCHITECTURE
-------------------------------------------------------------------------------
The "NASERC Core Engine" (`naserc-core`) is a dedicated WordPress plugin housing
all custom data structures, post types, regulatory documents, consumer complaint
escalation logic, email notification dispatches, and form shortcodes.

Decoupling Philosophy:
- Presentation (visual aesthetics, layout grids, header styling) remains in `naserc-theme`.
- Data architecture, custom post types (`hero_slide`, `naserc_document`,
  `naserc_complaint`, `naserc_inquiry`), REST APIs, and business logic are isolated in `naserc-core`.
- Ensures zero data loss if themes are switched or updated in the future.
- Companion Integration: Seamlessly integrates with the theme's TGM Plugin Activation
  (TGMPA) and 1-Click Page & Menu Setup Wizard.

3. CUSTOM POST TYPES (CPTs) & DATA SCHEMAS
-------------------------------------------------------------------------------
A. Hero Slider (`hero_slide`)
   - Purpose: Enables admins to easily manage homepage slider banners.
   - Fields: Featured Image, Slide Tag (e.g. "Recent Activity"), Headline, Excerpt, CTA Link.

B. Regulatory Instruments (`naserc_document`)
   - Purpose: Public informational repository of statutory regulations and standards.
   - Taxonomies: `naserc_doc_category` (Grid Code, Customer Protection, Mini-Grid Rules, Technical Standards).
   - Custom Meta Fields:
     - `_naserc_pdf_url` (Media Library Attachment URL or External Document Link)
     - `_naserc_file_size` (e.g. "3.4 MB")
     - `_naserc_effective_date` (e.g. "February 2026")
     - `_naserc_download_count` (Integer tracking total downloads)

C. Consumer Complaints Desk (`naserc_complaint`)
   - Purpose: Private administrative database for lodged consumer disputes and appeals.
   - Access: Secretariat & Legal Division roles only (Hidden from public front-end).
   - Custom Meta Fields:
     - `_naserc_docket_no` (Generated Reference, e.g. "NAS-ADJ-2026-8941")
     - `_naserc_disco_ticket_no` (DisCo Customer Care Unit Ticket Number - Step 1 Verification)
     - `_naserc_forum_ref_no` (Forum Office Case / Docket Reference - Step 2 Verification)
     - `_naserc_complainant_name`, `_naserc_phone`, `_naserc_email`, `_naserc_lga`
     - `_naserc_disco_provider` (e.g. AEDC, Karu Solar Mini-Grid)
     - `_naserc_meter_no` (Account or Smart Meter Number)
     - `_naserc_dispute_category` (Overbilling, Unmetered, Transformer Failure, Disconnection, Appeal)
     - `_naserc_status` (`pending_review`, `under_investigation`, `hearing_scheduled`, `resolved`, `rejected`)
     - `_naserc_attachments` (Array of attachment URLs: DisCo correspondence, Forum ruling, bills)
     - `_naserc_resolution_notes` & `_naserc_handler_id`

D. Secretariat Inquiries (`naserc_inquiry`)
   - Stores general inquiries from the Contact Us page.
   - Status: `unread`, `in_progress`, `closed`.

5. COMPLAINT SUBMISSION, DOCKETING & DUAL EMAIL NOTIFICATIONS
-------------------------------------------------------------------------------
When a consumer submits the formal Step 3 appeal docket:

A. Backend Processing Routine (`class-naserc-forms.php`):
   1. Validates Nonce token (`naserc_form_action`) and Honeypot anti-spam check.
   2. Sanitizes all inputs (`sanitize_text_field`, `sanitize_email`, `sanitize_textarea_field`).
   3. Validates uploaded files (PDF, PNG, JPG, Max 5MB, MIME type check).
   4. Generates unique docket code: `NAS-ADJ-{YEAR}-{RANDOM_4_DIGITS}` (e.g. `NAS-ADJ-2026-7412`).
   5. Creates `naserc_complaint` post in WordPress database with `post_status => 'publish'`.
   6. Saves all metadata fields (DisCo Ticket #, Forum Docket #, Meter #, LGA, Attachments).

B. Dual Automated Email Dispatches (`class-naserc-emails.php`):
   1. Complainant Acknowledgement Receipt:
      - Subject: "NASERC Appeal Docket Created - [NAS-ADJ-2026-XXXX]"
      - Recipient: Complainant's email address.
      - Content: Formatted HTML email containing Docket Number, filing metadata, DisCo & Forum references, and next steps regarding Secretariat docket review.
   2. Secretariat & Legal Unit Administrative Alert:
      - Subject: "New Formal Regulatory Appeal Docket Lodged: [NAS-ADJ-2026-XXXX]"
      - Recipient: Configured Secretariat email (e.g., `info@naserc.na.gov.ng`).
      - Content: Full details of the appeal, appellant contact information, DisCo & Forum reference numbers, attached documents, and direct link to the WP Admin complaint docket editor.


6. FORM SUBMISSION SECURITY & RATE LIMITING
-------------------------------------------------------------------------------
1. Nonce Token Security:
   - All forms embed `wp_nonce_field('naserc_form_action', 'naserc_nonce')`.
   - REST API handler validates nonces with `wp_verify_nonce()`. Rejects invalid requests with HTTP 403.
2. Honeypot Anti-Spam Trap:
   - Form includes visually hidden field `<input type="text" name="naserc_hp_check" tabindex="-1" autocomplete="off">`.
   - Rejects submissions instantly if filled by automated bots.
3. Transient IP Rate Limiting:
   - Maximum 5 submissions per 15 minutes per IP address.
   - Prevents DoS attacks and spam flooding by returning HTTP 429 Too Many Requests.
4. Database Prepared Statements:
   - All DB operations utilize `$wpdb->prepare()` or native WordPress post insert functions.


7. 1-CLICK PAGE GENERATION & NAVIGATION HELPER HOOKS
-------------------------------------------------------------------------------
1. TGMPA Compatibility:
   - Declares standard plugin headers enabling `naserc-theme` to automatically prompt for installation.
2. Setup Wizard Helper (`naserc_core_setup_default_content()`):
   - Hooked by `Appearance > NASERC Setup` to generate standard pages pre-populated with active shortcodes:
     - `Home` -> front-page.php
     - `About Us` -> page-about.php
     - `Regulations` -> page-regulations.php with `[naserc_docs_carousel count="8"]`
     - `Activities & News` -> page-activities.php
     - `Customer Complaints` -> page-forms.php with `[naserc_complaint_desk]`
     - `Contact Secretariat` -> page-contact.php with `[naserc_inquiry_form]` [naserc_hq_map]
   - Automatically builds the Primary Navigation Menu with full dropdown hierarchy and assigns it to the theme location.
