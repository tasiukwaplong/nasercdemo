1. EXECUTIVE OVERVIEW & ARCHITECTURE
-------------------------------------------------------------------------------
The NASERC WordPress Theme ("naserc-theme") will serve as the presentation layer
for the Nasarawa State Electricity Regulatory Commission official website.
It translates the static HTML5/Vanilla CSS/JavaScript frontend into a highly
performant, modern, accessible, and secure WordPress theme.

Core Functional Scope:
- Civic & Regulatory Presentation: Clean, authoritative presentation of the
  Commission's statutory mandate, leadership, news, and regulatory framework.
- Informational Repository: Public access and in-browser viewing / download of
  statutory regulations, grid codes, customer protection rules, and mini-grid standards.
- Consumer Complaint & Dispute Desk: Exclusive interactive civic service handling
  the mandatory 3-step complaint workflow (DisCo CCU -> Forum Office -> NASERC).
- Decoupled Plugin Engine: All data models, custom post types (`hero_slide`,
  `naserc_document`, `naserc_complaint`, `naserc_inquiry`), email dispatchers, and
  form shortcodes are encapsulated in the companion plugin `naserc-core`.
- Automated Onboarding: One-Click setup wizard creating all core pages and building
  the Primary Navigation Menu automatically.

3. COMPANION PLUGIN PROMPT & 1-CLICK ONBOARDING SETUP WIZARD
-------------------------------------------------------------------------------
A. Automatic Plugin Installation Prompt (TGMPA Integration):
   - Integrated via `inc/tgmpa-config.php` using the TGM Plugin Activation library.
   - Upon theme activation, if `naserc-core` is not active, an admin notification displays:
     > "This theme requires the following plugin: NASERC Core Engine. [Begin installing plugin] | [Dismiss this notice]"
   - Facilitates 1-click installation and activation directly from the WP Admin dashboard.

B. First-Time Setup & Onboarding Wizard (`Appearance > NASERC Setup`):
   - Step 1: Plugin Check & Activation
     * Verifies active status of `naserc-core`.
   - Step 2: 1-Click Page Creation & Shortcode Ingestion
     * Generates all required standard pages with their templates and shortcodes:
       -----------------------------------------------------------------------------------------
       Page Title           Target Slug   Template Assigned      Pre-Populated Content / Shortcode
       -------------------  ------------  ---------------------  -----------------------------------
       Home                 home          front-page.php         (Dynamic CPTs & Customizer)
       About Us             about         page-about.php         (Statutory Mandate & Leadership)
       Regulations          regulations   page-regulations.php   [naserc_docs_carousel count="8"]
       Activities & News    activities    page-activities.php    (Dynamic news query)
       File Complaint       forms         page-forms.php         [naserc_complaint_desk]
       Contact Secretariat  contact       page-contact.php       [naserc_inquiry_form] [naserc_hq_map]
       -----------------------------------------------------------------------------------------
   - Step 3: Site Automation & Navigation Menu Assignment
     * Automatically sets `show_on_front = 'page'` and `page_on_front = Home_Page_ID`.
     * Automatically creates the "Primary Navigation Menu" in WordPress with proper hierarchy
       (Home, About Us [Mandate, Vision, Governance], Regulations [Grid Code, Customer Protection,
       Mini-Grid], Activities, File Complaint) and assigns it to the theme's `primary-menu` location.


4. STATUTORY 3-STEP CUSTOMER COMPLAINT HANDLING PROCESS
-------------------------------------------------------------------------------
Consumers must follow the Commission's statutory 3-step hierarchical resolution process:

A. The 3-Step Complaint Flowchart:
   ┌─────────────────────────────────────────────────────────────────────────────┐
   │ STEP 1: DISCO (CCU) - Customer Care Unit                                    │
   │ 1. Customer lodges formal complaint with DisCo (AEDC or licensed Mini-Grid).│
   │ 2. DisCo CCU investigates and provides resolution within statutory 15 days. │
   │ 3. Decision Point: Do you agree with resolution?                            │
   │    • YES ──> DisCo notifies NASERC ──> [END / RESOLVED]                     │
   │    • NO  ──> Move to Step 2                                                 │
   └──────────────────────────────────────┬──────────────────────────────────────┘
                                          │ (If Unsatisfied / Timeline Exceeded)
                                          ▼
   ┌─────────────────────────────────────────────────────────────────────────────┐
   │ STEP 2: FORUM OFFICE (Electricity Consumer Complaints Forum)                │
   │ 4. Customer appeals to the Lafia / Zonal Consumer Forum Office.             │
   │ 5. Forum panel holds hearing with DisCo and issues formal ruling.           │
   │ 6. Decision Point: Are you satisfied with Forum's decision?                 │
   │    • YES ──> [END / RESOLVED]                                               │
   │    • NO  ──> Move to Step 3                                                 │
   └──────────────────────────────────────┬──────────────────────────────────────┘
                                          │ (If Unsatisfied with Forum Decision)
                                          ▼
   ┌─────────────────────────────────────────────────────────────────────────────┐
   │ STEP 3: NASERC ADJUDICATION & REGULATORY APPEAL                             │
   │ 7. Customer appeals to NASERC Secretariat for regulatory adjudication.      │
   │ 8. NASERC Legal & Technical Directorate reviews docket and issues ruling.   │
   │ 9. Decision Point: Do you agree with NASERC's final regulatory decision?    │
   │    • YES ──> [END / FINAL BINDING DETERMINATION]                            │
   │    • NO  ──> Seek judicial review / Court remedies.                         │
   └─────────────────────────────────────────────────────────────────────────────┘

B. Frontend Template & JS Screening Modal (`page-forms.php` / `[naserc_complaint_desk]`):
   1. Visual Flowchart Banner (`template-parts/components/complaint-flowchart.php`):
      - Informs citizens of the statutory 3-step sequence.
      - Action buttons launch the DisCo Directory modal or Forum Office Guide modal.
   2. Interactive JS Screening Modal Questionnaire:
      - Triggered by clicking "Start Eligibility Check".
      - Step 1 Check: "Have you lodged with DisCo CCU?" (If NO -> DisCo advice modal with AEDC lines 08039004030; If YES -> Was it resolved?).
      - Step 2 Check: "Have you appealed to the Forum Office?" (If NO -> Forum advice modal with Lafia hearing chambers info; If YES -> Was it resolved?).
      - Step 3 Qualification Screen: Unlocks and smoothly scrolls to the Step 3 Formal Appeal Form.
   3. Formal Appeal Docket Form:
      - Mandatory Fields: DisCo Ticket Number, Forum Docket Reference Number, Complainant Name, Phone, Email, LGA, Provider, Meter ID, Category, Description, and Attachment.
      - Submission triggers:
        * Unique Docket Number generation (`NAS-ADJ-2026-XXXX`).
        * Automatic Email Acknowledgement to Complainant with official hearing guidance.
        * Automatic Email Alert to NASERC Legal & Technical Unit (`info@naserc.na.gov.ng`).


5. SECTION MANAGEMENT & CONTENT UPDATING IN WORDPRESS
-------------------------------------------------------------------------------
Section                       Update Mechanism in WordPress
----------------------------  --------------------------------------------------
A. Header Logo & NASERC Name  - Managed via Appearance > Customizer > Site Identity.
                                Acronym color (#ce1126), font size, and tagline.

B. Top Bar Info & Hotline     - Managed via Customizer > NASERC Header Settings.
                                Editable: Hotline (0800-NASERC-HOT), Email, Hours.

C. Compact Green Stats Bar    - Managed via Customizer > Civic Statistics.
                                Editable counts: Mini-Grids, Resolved Complaints,
                                Operator Licenses, LGAs.

D. Hero Slider Banner         - Custom Post Type `hero_slide`.
                                Admin creates slides with Title, Image, Tag,
                                Excerpt, and CTA Link.

E. Executive Chairman Quote   - Managed via Customizer > Executive Statement.
                                Photo upload, Chairman Name, Title, Excerpt Quote,
                                and Full Address Speech Text (for modal reader).

F. Regulatory Repository      - Managed via Custom Post Type `naserc_document`.
                                Taxonomies: Grid Code, Consumer Protection,
                                Mini-Grid Rules, Technical Standards.
                                Custom fields: PDF upload/link, file size, date.

G. Header Nav & Mobile Drawer - Desktop: Full horizontal navbar with dropdowns.
                                Mobile (<=1024px): "Contact Us" button in sticky header
                                is cleanly hidden; accessible inside the slide-out drawer.

H. Footer Social Links        - Managed via Customizer > Social Links.
                                Links to X (@nasercnas), Facebook, Instagram, LinkedIn.


6. SPEED & PERFORMANCE OPTIMIZATION STRATEGY
-------------------------------------------------------------------------------
1. CSS & JS Enqueuing:
   - Enqueue minified `styles.min.css` with versioning based on `filemtime()`.
   - Add `defer` attribute to non-critical JS scripts (`slider.js`, `counters.js`).
2. Resource Preloading & Google Fonts:
   - Preload Google Fonts (Plus Jakarta Sans & Inter) via `<link rel="preload">`.
   - Add `font-display: swap` for zero Cumulative Layout Shift (CLS).
3. Image Optimization:
   - Support native WebP images with `srcset` and `sizes` attributes.
   - Enforce `loading="lazy"` on images below the fold.
4. Micro-Transient Caching:
   - Cache regulatory documents and hero queries using WordPress Transients API:
     `set_transient('naserc_home_docs_query', $docs_query, 12 * HOUR_IN_SECONDS);`
   - Automatically purge transients when a document or slide is updated (`save_post`).
5. Clean Footprint:
   - Disable Emojis and unnecessary WordPress block CSS on non-editor templates.
